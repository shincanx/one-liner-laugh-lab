Entry for the [make.fun bounty "One-Liner Laugh Lab"](https://make.fun/bounty/u-suroso-69-one-liner-laugh-lab-6ccf3aae) — a single short funny line answering a prompt, like the excuse a robot vacuum gives after eating a sock, at most 200 characters.

## Run

```sh
python3 main.py
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). No network, no dependencies, deterministic.
